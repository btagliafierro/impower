# IM-POWER Website

Static website for the IM-POWER project built with MkDocs and Material for MkDocs.

## Requirements
- Python 3.9+
- pip or pipx

Install dependencies (choose one):

```bash
# pipx (isolated, recommended)
pipx install mkdocs mkdocs-material mkdocs-bibtex mkdocs-awesome-pages-plugin

# or pip (inside a virtualenv is recommended)
pip install mkdocs mkdocs-material mkdocs-bibtex mkdocs-awesome-pages-plugin
```

## Project structure
- `mkdocs.yml` — site configuration (theme, nav, plugins)
- `docs/` — documentation source (markdown, assets)
  - `pages/` — content pages (Main, Background, Overview, Implementation, Outcome, Contact)
  - `figures/` — images used in pages
  - `stylesheets/`, `mathjaxhelper.js` — extra assets
  - `bib.bib` — bibliography (used by mkdocs-bibtex where referenced)
- `overrides/` — theme overrides (footer, templates)
- `site/` — built output (generated by `mkdocs build`)

## Local development
Run a live-reloading dev server:

```bash
mkdocs serve
```

Then open the URL shown (typically `http://127.0.0.1:8000`).

## Build
Generate the static site into `site/`:

```bash
mkdocs build --clean
```

## Deploy
### GitHub Pages (free, public repos)
```bash
mkdocs gh-deploy --clean
```
Notes:
- In your repo: Settings → Pages → set Source to “Deploy from branch: gh-pages”.
- Ensure `site_url` in `mkdocs.yml` is `https://<user>.github.io/<repo>/`.

### Netlify / Cloudflare / Vercel (free tiers)
- Build command: `mkdocs build`
- Publish/output directory: `site`

## Common tasks
- Update year: edit `copyright` in `mkdocs.yml`.
- Change logo or favicon: update paths under `theme:` in `mkdocs.yml` and files in `overrides/assets/images/`.
- Add a page: create `docs/pages/new_page.md` and add it to `nav` in `mkdocs.yml`.
- Citations: add entries to `docs/bib.bib`. To render on a page, either insert a formatted reference in markdown or configure a citation extension; the site currently lists formatted references directly on pages like `Outcome → Conferences & Papers`.

## Troubleshooting
- Logo click goes to 404:
  - Confirm `site_url` in `mkdocs.yml` matches your GitHub Pages URL.
  - Ensure a root `docs/index.md` exists (this repo includes an automatic redirect to `pages/`).
- Changes don’t appear:
  - Clear browser cache or run `mkdocs build --clean`.
- Missing images/links:
  - Use relative links from the current file; ensure targets exist under `docs/`.
